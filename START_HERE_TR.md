# Takım için — GitHub yükleme yönergesi

1. ZIP'i bilgisayara **çıkarın**. GitHub'a tek bir ZIP dosyası yüklemek yerine içindeki `README.md`, `floot_project/`, `database/`, `docs/`, `scripts/`, `assets/` ve `MANIFEST.json` dosyalarını depo köküne yükleyin.
2. Yeni bir GitHub deposu oluşturun. Görünürlüğü **Public** yapın. Repository adı için `spherex-sky-explorer-2026` uygundur.
3. `README.md` ve `docs/SCIENCE_METHOD.md` belgelerindeki bilimsel sınırlamaları koruyun. Veri satırları ve kaynağı saklayın; kimlik bilgileri veya `.env` dosyaları eklemeyin.
4. GitHub'da dosya sayısı çoksa bilgisayardan `git add .`, `git commit`, `git push` kullanın. ZIP'in içeriğini GitHub web arayüzünde de yükleyebilirsiniz; web arayüzü ZIP'i otomatik açmaz.
5. GitHub'daki bağlantının dışarıdan giriş yapmadan açıldığını kontrol edin. Başvuruya hem depo linkini hem çalışan siteyi ekleyin: https://www.cemberlitasmeninhack.com/
6. Veritabanı JSONL arşivi büyükse GitHub'ın 100 MB tek dosya sınırına bakın; büyük veri için Git LFS veya ayrı araştırma-verisi bağlantısı gerekebilir.
7. Floot'a özgü kaynaklar için README'deki `Floot-native` açıklamasını saklayın. Bu ZIP, Floot'un kapalı kaynak çalışma ortamını veya özel erişim anahtarlarını içermez.
8. NASA başvurusu teslim edildiğinde onay/confirmation sayfasının görüntüsünü kaydedin.
